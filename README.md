# Superstore Sales Analysis

## Project Overview
End-to-end sales analysis of 9,994 retail transactions 
across the United States (2014–2017) using Excel, 
SQL, and Power BI.

## Tools Used
- Microsoft Excel — data cleaning & pivot analysis
- SQLite (DB Browser) — business query analysis
- Power BI Desktop — interactive dashboard

## Key Insights
- November consistently peaks every year (holiday demand)
- Tables sub-category loses money despite high sales volume
- High discounts (41%+) generate negative profit overall
- West region leads in both revenue ($725K) and 
  profit margin (14.94%) — strongest market overall
- Central region has the weakest margin (7.92%) 
  despite outselling the South — discount issues likely
- Consumer segment drives 50.56% of total revenue

## Files in This Repository
- /excel — cleaned dataset, pivot table, charts
- /sql — all 4 SQL queries + result screenshots
- /powerbi — dashboard PDF and screenshot
